## General Info  
This repository contains the code for **Product Service** - one of the core microservices of **Shopiqo**, a full-stack e-commerce platform.  
The Product Service is developed using **Java** and **Spring Boot** and is responsible for:  
- Managing products
- Reading, sorting, and searching for products  
- Handling related data, such as product categories
